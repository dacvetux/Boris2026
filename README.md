# Boris2026

Minimal React/Vite landing page for Boris Sovič, prepared for GitHub Pages deployment.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

GitHub Actions deploys the `dist/` output to GitHub Pages on every push to `main`.
